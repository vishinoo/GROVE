# Grove roadmap, against what is actually built

**Date:** 2026-09-06

The ten-point plan, marked honestly. Several items are further along than they
look; two cannot be built at all on iOS and should stop being planned for.

## 1. Memory — BUILT, thinner than described

`memory.ts`: 40 capped facts, extracted locally by keyword, sent whole in every
prompt, readable and deletable in Settings and on Sparks.

What is missing is the example given: *"remind me what I was supposed to ask
Sarah about"*. That needs facts attached to a person and a time, not a flat list
of sentences. The shape to move to is `{ subject, claim, when, source }` — still
capped, still flat, still no embeddings.

## 2. Eyes — BLOCKED ON HARDWARE, not on software

Nothing about the current glasses is a camera; they are a Bluetooth headset
(`AGENTS.md`). There is no video path and no way to add one. This is a hardware
decision, not a backlog item.

## 3. Do things — 9 of ~15 BUILT

Working: weather, day brief, calendar read, move event, reminders, mail read,
mail send, contact lookup, music, maps ETA.

Impossible on iOS, permanently: reading Messages, sending a message without a
tap, reading another app's notifications, placing a call programmatically. No
API, no entitlement. These should be removed from the plan rather than deferred.

Not built but possible: web search, news, finance, smart home (HomeKit), notes.

## 4. Grove Agent — THE ARCHITECTURE IS ALREADY THIS

`grove.ts` is already: understand intent → choose ability → execute → report.
`day.brief` is the first compound one and shows the pattern for "handle my
morning". More of those, not a different architecture.

## 5. Proactive — HALF BUILT

Sparks are the mechanism. `dueSparks` catch-up runs on foreground. Missing is
the server half: a true 7am briefing with the phone asleep needs Noctus to run
it and push, which does not exist. Rate control does not exist either and is the
part worth designing carefully.

## 6. Personality — BUILT

`persona.ts`: a name, a manner in the user's own words, quarantined as style.
`HOUSE_RULES` already forbids the assistant register. Presets were deliberately
removed as a second source of truth for one setting.

## 7. Voice — BUILT, except the wake word

Tap-to-talk, barge-in, on-device recognition, sentence-level interruption
tracking, voice picking. "Hey Grove" needs continuous listening, which is a
battery and privacy decision rather than a feature.

## 8. Modes — NOT BUILT

Cheapest real item on this list: a mode is a persona plus a set of enabled
abilities plus a spark group. Mostly composition of things that exist.

## 9. World model — NOT BUILT

Depends on (1) growing up first. A flat fact list cannot answer "should I go to
the gym"; a subject-predicate store might.

## 10. Second brain app — PARTLY

Sparks and Memory exist as screens. "Today" does not.

## The order I would actually take

1. Memory shape — unlocks 9, and makes 1 do what the example promises
2. Modes — cheap, mostly composition
3. Server-side spark execution + push — makes 5 real
4. More abilities: search, news, finance, HomeKit
5. Wake word — only after deciding the battery and privacy trade
